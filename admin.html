Aktualizácia dát kampaní (TU)

Táto stránka beží len vo vašom prehliadači – nič sa nikam neodosiela. Vytvorí zašifrovaný súbor data.json, ktorý nahráte na web.

Stĺpce: A = Kód dealera (ID), B = Skrátený názov, C = PIN. Tento súbor nikdy nenahrávajte na web.
Prvý hárok, rovnaká štruktúra stĺpcov ako doteraz.
Potom:
  1. Otvorte svoj repozitár na GitHube → Add file → Upload files.
  2. Pretiahnite stiahnutý data.json (prepíše starý) → Commit changes.
  3. Po cca 1 minúte je nový zoznam na webe.
